## 🚀 Hướng Dẫn Cài Đặt Cho Người Dùng
1. Tải tệp **`CloudSaveSync-Setup.exe`** về máy tính.
2. Bấm đúp chạy file để mở trình cài đặt Windows Setup Wizard.
3. Chọn thư mục cài đặt (mặc định `%LOCALAPPDATA%\CloudSaveSync`) và bấm **Cài đặt**.
4. Ứng dụng sẽ tự tạo shortcut trên Desktop & Start Menu và tự động kích hoạt bảo vệ Save Game!
